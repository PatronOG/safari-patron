Third-party code and data used in Safari Patron
================================================

Hypixel SkyBlock Wiki contributors - see Critter-Icons.txt and Critter-Icon-Sources.json
  https://hypixelskyblock.minecraft.wiki/w/Critter_Safari
  36 critter list sprites (Scrappy from the Minecraft Wiki); original Minecraft/Hypixel art rights are retained.

Nebulune (Copyright (c) 2025, Starred) - BSD 3-Clause, see Nebulune-BSD-3-Clause.txt
  Critter detection, floor drop detection and ESP colors
  (esp/CritterId.kt, esp/Esp.kt, data/Critters.kt)

CritterMod (Copyright (c) 2026 MrCloudy2) - MIT, see CritterMod-MIT.txt
  https://github.com/MrCloudy2/critterMod
  Biome list and rarity groups, bee nest and Snoozle wall positions
  (data/Critters.kt, esp/Structures.kt)

SkyHanni - LGPL-2.1, see SkyHanni-LGPL-2.1.txt
  https://github.com/hannibal002/SkyHanni
  Critter Safari area graph nodes (assets/safari-patron/safari_areas.txt, data/AreaMap.kt)

Sparkling Mutuals (johnceoskyblock) - CC0 1.0
  https://github.com/johnceoskyblock/sparkling-mutuals
  Torrhus Canyon honeyhive positions, first surveyed by Shiny Hunter
  (https://github.com/javabetter/ShinyHunter)
  (assets/safari-patron/honeyhives.txt)

SkyCofl (https://sky.coflnet.com) - public API
  Auction House lowest BIN prices for the Emerald Dye (profit/Auction.kt)

hm-api (AzureAaron) - Apache-2.0
  Bundled inside the jar with its own license.

Sparkling Mutuals (johnceoskyblock) - CC0 1.0, see Sparkling-Mutuals-CC0.txt
  https://github.com/johnceoskyblock/sparkling-mutuals
  Floor display grouping, resource-order model and interaction helper references.
  The new classifier retains competing layouts and does not apply the original
  first-observed anchor or preferred-Icebreaker-count heuristic.

SafariUtils (Copyright (c) 2026 Serkosea and MrCloudy2) - MIT, see SafariUtils-MIT.txt
  https://github.com/Serkosea/safariutils
  Resource-prefix model and mound site/shape references via Sparkling Mutuals
  (resources/FloorDropModel.kt, helpers/MoundClickClock.kt, assets/safari-patron/mound_sites.txt).

Nebulune (Starred) - BSD 3-Clause, see Nebulune-BSD-3-Clause.txt
  Repeated mound-attack cadence reference (helpers/MoundClickClock.kt).

Hypixel SkyBlock Wiki contributors - resource sprites
  See Floor-Drop-Icons.txt and Floor-Drop-Icon-Sources.json for sources and rights.
